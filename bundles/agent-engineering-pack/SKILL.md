# Agent Engineering Pack

Apply `engineering-baseline`, `task-contract`, `agent-delegation`,
`contract-integrity`, and `issue-to-production` for agent-generated changes.

The agent must state scope, dependencies, exact commands, target environment,
and completion evidence. Assertions or summaries do not replace executed
verification.
