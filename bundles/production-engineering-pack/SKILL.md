# Production Engineering Pack

Install this bundle when an agent works on a deployed application or service.
Apply the included skills together:

`engineering-baseline`, `issue-to-production`, `contract-integrity`,
`deployment-truth`, `database-change-safety`, `configuration-parity`,
`observability-correctness`, `security-boundaries`.

The bundle does not replace project-local commands or adapters. Load the
relevant specialist skill before editing and produce the strongest evidence
required by the changed boundary.
