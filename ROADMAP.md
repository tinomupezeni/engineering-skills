# Roadmap

The roadmap is intentionally outcome-focused. Ideas are welcome through
[GitHub Discussions or issues](https://github.com/tinomupezeni/engineering-skills/issues).

## Near term

- Add more end-to-end examples for common AI coding-agent workflows.
- Document compatibility notes for popular skill-consuming agents.
- Add a lightweight release checklist and versioned pack metadata.
- Collect real-world feedback from teams using the skills in production.

## Later

- Add portable checklists for performance and accessibility work.
- Publish a searchable catalog of skills and bundles.
- Add automated checks for example links and documented install commands.

## Not planned

- Project-specific deployment instructions in the public pack.
- A replacement for a team's own architecture, security, or release policy.
- Claims that installing a skill alone makes an agent safe.
