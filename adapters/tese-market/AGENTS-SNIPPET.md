## Engineering Skills Baseline

Use the portable engineering controls from
`https://github.com/tinomupezeni/engineering-skills`. Apply
`engineering-baseline` to every task and load the specialist skill matching the
boundary being changed.

For BFF, storefront, admin, database, or deployment changes, verify both sides
of every API contract and use the project test commands from the adapter.
Production smoke and deployment commands require explicit production approval.

Project adapter: `adapters/tese-market/ADAPTER.yaml`.
