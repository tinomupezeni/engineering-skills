## Engineering Skills Baseline

Use the portable engineering controls from
`https://github.com/tinomupezeni/engineering-skills`. Apply
`engineering-baseline` to every task and load the specialist skill matching the
boundary being changed.

For webhook, portal, backend, or deployment changes, preserve contract evidence
between producers and consumers and run the strongest project validation
available from the adapter. Do not treat local tests as staging proof.

Project adapter: `adapters/smepulse/ADAPTER.yaml`.
