## Engineering Skills Baseline

Use the portable engineering controls from
`https://github.com/tinomupezeni/engineering-skills`. Apply
`engineering-baseline` to every task and load the specialist skill matching the
boundary being changed.

Before editing, state scope, affected backend/frontend/worker boundaries, exact
validation commands, and target environment. Keep the known frontend timeout
baseline separate from new failures. Do not claim staging or production
verification from local tests.

Project adapter: `adapters/tesc/ADAPTER.yaml`.
