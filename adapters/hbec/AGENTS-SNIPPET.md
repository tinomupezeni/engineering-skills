## Engineering Skills Baseline

Use the portable engineering controls from
`https://github.com/tinomupezeni/engineering-skills`. Apply
`engineering-baseline` to every task and load the specialist skill matching the
boundary being changed.

Before editing, read the relevant project memory and state files, state scope
and dependencies, and name the exact validation command. Do not claim target
environment work from local tests. For deployments, migrations, replication,
authentication, workers, external providers, or UI/device behavior, produce
the corresponding staging or real-target evidence.
